How it all works

The rules every data job follows are in DATA-UPDATES.md ↗; the visitors' version is How the data is collected; every run is on GitHub Actions ↗. This page is not in the menus or the footer, and search engines are asked not to list it.

Read from the jobs' status files, dev/data_jobs.json and GitHub's public lists of the site's runs, commits and data-health issue (api.github.com, no key; GitHub allows 60 requests an hour per visitor, so the lists are kept for 3 to 15 minutes in this tab).
